# Grok Auto Register Factory

Công cụ tự động đăng ký tài khoản Grok / xAI.

## Cấu hình

1. Sao chép file cấu hình mẫu:
   ```bash
   cp .env.example .env
   ```
2. Cập nhật các thông số API Key trong file `.env`.

## Hướng dẫn cài đặt

```bash
pip install -r requirements.txt
```

## Chạy công cụ

```bash
python register_grok.py
```
